SA/DV Data Atlas Prototype

Make the invisible system visible.

A Python-generated prototype for representing sexual violence data without reducing survivors to data points: burden, access gaps, prevention practice, evidence, services, and privacy rules in one atlas.

Design principle

Use many visual forms, not one giant chart.

Sexual violence data spans surveys, official reports, hospital/SANE access, prevention implementation, evidence citations, resource availability, geography, policy, and survivor-controlled records. The right system is an atlas: charts for burden, maps for access, networks for pathways, timelines for change, and strict privacy boundaries for survivor data.

Evidence to action

Connect PMIDs and guidance to practices people can deploy.

A network view is useful because the same source can support multiple practices, and the same practice can require several kinds of evidence. This is the structure behind a living evidence library.

Python libraries

Recommended stack for enormous data.

Only pandas and numpy are installed in the current bundled environment, so this prototype is pure Python/HTML/SVG. For production-scale work, install the stack below by layer rather than trying to make one visualization library do everything.

Survivor-safe analytics

Do not visualize what should remain private.

Rule 1

Separate surveillance from vault data

Use CDC, BJS, FBI, state, campus, hospital, and community datasets for public burden and access visuals. Survivor-controlled documentation should not feed dashboards by default.

Rule 2

Aggregate before sharing

Suppress small cells, remove identifiers, use geography carefully, and never publish combinations that make a survivor recognizable.

Rule 3

Show uncertainty and definitions

Rape, sexual assault, contact sexual violence, made-to-penetrate, harassment, technology-facilitated harm, reports, and prevalence surveys are not interchangeable.

Rule 4

Make evidence clickable

Every research claim should link to PMID when available; official guidance should be labeled as official guidance, not PubMed evidence.

Sources: CDC About Sexual Violence; CDC Sexual Violence Prevention; CDC Public Health Approach to Violence Prevention. Planning prototype only; not clinical, legal, forensic, or crisis guidance.
